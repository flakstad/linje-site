Privacy

Access-request data is only used to provision Linje.

When you request access by email, Linje uses the information you send to respond and provision access to the portal and project setup flow.

When analytics are configured, the public site records page views, the market surface that led to the visit, campaign parameters, and explicit call-to-action clicks. Session replay and automatic interaction capture are disabled. Query strings are removed from captured page and referrer URLs, IP addresses are discarded, and Linje does not send email addresses, message contents, attachment names, or application metadata to public-site analytics.

PostHog runs in cookieless mode. A first-visit surface and campaign may be stored only for the current browser-tab session so a later access request can be attributed to the page that introduced Linje. Google Search Console provides aggregate search-query and page-performance data for the site.

To request removal of access-request data, email hello@linje.systems.
